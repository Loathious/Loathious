### Protocol

A personal training and performance system built around adaptive programming. Protocol combines training science, statistical modelling and personal data to create a system that continuously learns and evolves with its user.

<details>
<summary>How it's built</summary>

- Adaptive training engine with personalised strength, fatigue and recovery models.
- Statistical progression, volume management and nutrition adjustments.
- Predictive focus modelling and automated daily planning.
- Next.js 16, React 19, TypeScript, Dexie and Upstash Redis.
- Offline-first architecture with automated testing.

</details>

[Try Protocol](https://protocol-xi-six.vercel.app/)

### Archvfinds

A fashion discovery platform bringing together archive labels, independent brands and cross-border shopping. One catalog, multiple buying agents, and a unified link system that makes the entire experience seamless.

<details>
<summary>How it's built</summary>

- Static Next.js architecture with automated catalog generation.
- Universal buying-agent link conversion.
- Custom discovery and popularity algorithms.
- First-party analytics and a custom Discord bot.

</details>

[Archvfinds.com](https://archvfinds.com)
